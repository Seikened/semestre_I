# Semestre I - Repositorio Académico

Este repositorio contiene el material y proyectos desarrollados durante el primer semestre, enfocados en programación con Python e Inteligencia Artificial.

## 📁 Contenido del Repositorio

### 🐍 Clases_Curso_Python
Material del curso de Python organizado por temas:
- **tipos/** - Variables, strings, números, conversión de tipos
- **control-flujo/** - Comparadores, if/else, operadores lógicos, ciclos for/while
- **funciones/** - Funciones, *args, **kwargs, return, depuración
- **tipos-avanzado/** - Listas, tuplas, sets, diccionarios y sus operaciones
- `A03_matrices.py` - Trabajo con matrices

### 🤖 Herramientas de IA
Proyectos y prácticas de Inteligencia Artificial:
- **Reto_python/** - Ejercicios de factorial, sumatoria, palíndromos, sumas vectoriales
- **practica_2/** - Módulos y scripts adicionales
- `test.py` - Archivo de pruebas

### 📊 Probabilidad
Scripts para análisis de datos y estadística:
- `extractorDatos.py` - Extracción de datos
- `intervlos.py` - Cálculo de intervalos
- `muestas.py` - Trabajo con muestras
- `dataBase.csv` / `dataBase_modificada.csv` - Bases de datos para análisis

### 💻 Programacion_Aplicada_S1
Material de Programación Aplicada del Semestre 1:
- **clases/** - Clases en Python (barajas, gráficas, random, juegos)
- **tareas/** - Tareas del curso (conversores, fórmulas, ciclos, listas)
- **repasoExamen/** - Ejercicios de repaso para exámenes
- `proyectoFinal.py` - Proyecto final del curso

### 📐 fomulasProbabilidad
Implementaciones de fórmulas de distribuciones de probabilidad:
- `A1_distribucionBinomialAcumulada.py` - Distribución Binomial Acumulada
- `A2_distribucionBinomial.py` - Distribución Binomial
- `A3_distribucionPoisson.py` - Distribución de Poisson
- `A4_distribucionPoissonAcumulada.py` - Distribución de Poisson Acumulada
- `distribucionNormal.py` - Distribución Normal

## 🛠️ Tecnologías Utilizadas
- Python 3.x
